  左手は素手で、構え手・引き手・脇に置く（`src/character/data/offhand.ts`）。
- 制約①: iPad は両親指。ボタンが増えるほど指の置き場が窮屈になり、誤爆も増える（画面の右下に攻撃・回避・重・LOCK がすでにある）。
- 制約②: 技 1 本は手付けで数時間かかる。**「入力は少なく、文脈で技が変わる」**ようにして、作る本数と覚える量を抑える。
- 追い風: 手付けの仕組み（ADR-012）に `continueFrom`（前の技の姿勢から続ける）と、斬りの面のパラメータ化（`plane(θ, tilt)`）がある。
  新しい技は「面・向き・起点・踏み込み」を変えた部品の組み合わせで作れ、つなぎ目の姿勢も共有できる。

## 1. コマンドを増やさずに技を増やす軸

| 軸 | 例 | 追加の実装コスト | 備考 |
|---|---|---|---|
| 入力の種類 | タップ / 長押し（溜め）/ 離し | 小（押下時間を数えるだけ） | 長押しの判定を待つと全攻撃が遅れる。**押した瞬間は軽攻撃の予備動作に入り、まだ押していたら溜めに移る**形が定番 |
| スティック方向（押した瞬間） | 前 / 後ろ / 横 / 無入力 | 小（`beginAttack` に方向が渡っている） | 1 撃目だけ変えるのが分かりやすい。ロックオン中は「敵に対して」の方向 |
| コンボ位置 | 1〜3 段目、段の途中の早押し / 遅押し | 小 | 段ごとに分岐（例: 2 段目の後でスティック後ろ → 回転斬り） |
| 直前の行動 | 回避直後 / ガード成功直後 / 被弾直後 | 中（状態機械に遷移を足す） | 回避直後の攻撃は `continueFrom` で安く作れる |
| 間合い（ロックオン距離） | 遠い → 踏み込み斬り、近い → 通常 | 中（距離でどの技を出すか選ぶ） | 同じ入力で状況に合う技が出る |
| タイミング | ジャスト回避 / ジャストガード（敵の攻撃の直前） | 大（敵の攻撃判定と時間が要る = M2 以降） | 反撃の大技を出す口にできる |

## 2. 斬りの語彙（モーション部品）

斬りは「面の傾き（tilt）× 回る向き × 起点 × 踏み込み」で決まる。作った技と、同じ部品で作れる技:

| 斬り | tilt | 状態 |
|---|---|---|
| 右袈裟（右上 → 左下） | 38° | ✔ combo1 |
| 右逆袈裟（左下 → 右上） | 38° | ✔ combo2 |
| 右の突き | — | ✔ combo3 |
| 縦斬り（唐竹割り、頭上 → 前下） | 90° | ✔ heavy |
| 横薙ぎ（右 → 左） | 0° | ✔ sweep（ロック中の横 + 攻撃）。下がりながらの払い retreat も同じ水平の面 |
| 斬り上げ（右下 → 左上、逆袈裟） | −35° | ✔ dash（ロール直後）。縦の面（90°）で下から振り上げると、途中で剣が真下を向いて低い構えから剣先が床を貫く（実測 −0.4m）ので、右下がりの斜めの面にした |
| 踏み込み突き（水平） | — | ✔ lunge（前 + 攻撃、後ろステップの直後） |
| 高い突き / 低い突き | — | 突きの高さ違い（lunge の thrust の仰角を変える） |
| 回転斬り（体を 1 回転） | 0° | 要検討: 胴のひねり（yaw）が ±180° を超える。1 回転を 2 区間に割って連続にする必要あり（手首のねじれの折り返しと同じ注意） |
| 払い上げ・柄打ち・蹴り | — | 足や左手を使う技。拡張フェーズ |

## 3. コマンド構成の案

### 案 A: 攻撃 / 回避 / ガード（**採用**。ADR-013）

ソウルライク定番の 3 つ。**盾（左手）の役割がそのままボタンになる**ので、左手の件（盾 or 素手）と素直に噛み合う。

- **攻撃**
  - タップ: 袈裟 → 逆袈裟 → 突き（現行）
  - 長押し: 溜め → 重撃（縦斬り。押した瞬間は軽攻撃の予備動作 → 長押しなら頭上の構えで止まる）
  - スティック前 + 攻撃: 踏み込み突き（距離を詰める）
  - スティック後ろ + 攻撃: 後ろへ下がりながらの払い（間合いを取り直す）
  - スティック横 + 攻撃: 横薙ぎ（横へ回り込みながら）
  - 回避直後の攻撃: ダッシュ斬り（回避の勢いを乗せた斬り上げ）
  - 3 段目の長押し: フィニッシュ変化（突き → 打ち上げ）
- **回避**: スティック方向へのダッシュ（現行）。ジャスト回避（敵の攻撃が当たる直前）→ 攻撃で反撃の大技
- **ガード**（盾あり: 保持で構える、敵の攻撃の直前のタップで弾く / 盾なし: 剣を体の前に立てて受ける）

数の目安: 攻撃だけで 8〜10 技、ガード側で 2〜3 技、反撃で 1〜2 技。**ボタンは 3 つのまま 13 技前後**。

### 案 B: 弱 / 強 / 回避（攻撃を 2 ボタンに）

弱（L）と強（H）の並びで技が変わる（アクションゲームの「ストリング」）。例: L-L-L（現行の 3 連）/ L-L-H / L-H / H / H-L / L-L-L-H …
- 利点: 技の出し分けが直感的で、並べ方で十数本に増える
- 欠点: 作る本数も同じだけ増える。強ボタンは回避・弱と隣り合って誤爆しやすい。ガード（盾）に割り当てるボタンが無い

### 案 C: 攻撃 / 回避 / 特技

特技は「剣技」を 1 つ装備してクールタイムで出すボタン（装備で中身が変わる）。
- 利点: 装備で変化が付けられ、ボタンは 3 つ。成長要素と相性が良い
- 欠点: 成長・装備のシステムが先に要る（M3 を越えてから）

## 4. 左手: 盾 / 素手

左手のスロットは「盾 or 何も持たない」の 2 状態になる想定。見た目は **左腕のポーズ（`offhand.ts`）を装備で差し替える**形で表す。

- **素手**: 力を抜いて軽く握った手のまま、構え手（体の前）・引き手（左腰）・脇に置く。指ボーンが無いので握りや開きは変えられない
  （変えるには指ボーン付きで再リグ → 拡張フェーズ）。腕をまっすぐ伸ばさず、肘を曲げて体の近くに置くと自然に見える。
- **盾**: 盾のメッシュを左前腕ボーン（`foreL`）に固定する。
  - 構え（保持）: 肘を曲げて前腕を立て、盾面を敵へ向ける（左手首の位置 + 手の向きの指定が要る。今は位置だけなので、手の回転目標を足す）
  - 弾き（パリィ、タップ）: 盾を前へ突き出して 6〜8 フレームの受付。成功すると敵が体勢を崩し、直後の攻撃が反撃になる
  - 盾持ちの攻撃では、左腕は盾の持ち位置（体の左前）に固定。引き手の動きは使わない
- 必要なもの（M3 後）: ① 盾のメッシュ ② 左手の回転制御（`pose-solver`）③ ガード状態と判定（`player.ts` + 戦闘ロジック）④ 敵の攻撃側の「弾かれ」反応

## 5. 作る順番の提案（M3 の後）

1. ✔ 回避直後のダッシュ斬り（`continueFrom` で安く作れる。入力軸「直前の行動」の確認にもなる）
2. ✔ スティック方向の 1 撃目 3 種（前突き / 後ろ払い / 横薙ぎ）
3. ✔ 溜め（長押し）→ 重撃（1 段目の予備動作の途中から頭上の構えへ移って保持。段階で威力が上がる）
4. ガード / パリィ（盾）— M4-2
5. ジャスト回避の反撃

実装の覚え書き（ADR-018）: 斜めの面や広い横薙ぎでは、腰・胸のヨーと剣の面の角度（θ）が**足し算**で効く（例: 腰 22° + 胸 36° + θ 78° = 世界で 136°）。
思ったより回り込む（剣が真後ろまで行く）ときは、まず各ヨーを足して世界の角度を確かめる。手首のねじれが 150° を超えるときは、そのキーの `roll`（刃の軸まわり）を動かして減らす（`node tools/motion-check.mjs --trace <クリップ>` で超えた位置を探す）。
