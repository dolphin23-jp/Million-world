  三角形数は影パス 1 回と輪郭線パスを含む（キャラ 59k × 3 ≒ 177k）。
  - 実機計測の結果、fps は解像度に比例して落ち、ポストの構成が支配的だった。対策として ADR-011 を入れた（2026-10-03）: ポストを「シーン → 最終 1 パス」の 2 工程に減らし（画面サイズ・MSAA のパスが 3 → 1）、解像度の動的調整（1.5 → 1.25 → 1.0）を追加。実機の再計測で 60 fps（dpr 1.50）に達した。
  - 残る候補: ③ キャラ 59k 三角形が 影・本体・輪郭線で 3 回描かれる ④ 影マップ 2048²。再計測の結果次第で着手する

## M4 — 戦闘システムの確立（拡張フェーズ 1）

方針（2026-10-04、本人）: **世界（ステージ・敵の種類・成長）を広げる前に、戦闘システムをある程度確立させる。**
武器を 2 系統（片手剣 + 盾 / 両手の大剣）にし、ガードとパリィを入れ、回避のモーションを作り直し、片手剣もコマンドの組み合わせで技を増やす。
段階ごとに PR を分け、実機で確かめてから次へ進む。

### M4-1 回避の作り直し + コマンド基盤 + 片手剣の技の増加
- [x] 回避の作り直し（ADR-019。実機確認は未）: 実機で「モーションが崩れている」。大股のダッシュ（両足 1.5m 開き、剣が体の横へ突き出る）をやめ、**前転（ロール）と後ろへのステップ**にする。ロールは向きを入力方向へ合わせて転がる、入力なしやロック中に後ろへ倒すと向きを保ったまま後ろへ跳ぶ
- [x] モーションシート（`tools/motion-sheet.mjs`）: 手付けクリップをゲーム内で 1 フレームずつ送り、定点のカメラで撮って 1 枚に並べる（実機が無くても動きを目視で検査できる）
- [x] コマンド基盤（ADR-018）: 武器ごとの技のセット（moveset）と、入力（タップ / 長押し / スティック方向 / 直前の行動）から技を選ぶ純粋関数（vitest）。暫定の「重」ボタンを廃止し、**攻撃の長押しで溜め → 離して重撃**（ADR-013）
- [x] 片手剣の技を増やす（実機確認は未）: ① 回避直後のダッシュ斬り ② スティック前 = 踏み込み突き / 後ろ = 後ろへ下がりながらの払い / 横 = 横薙ぎ（ロック中は対象に対しての方向）③ 長押しの溜め → 重撃（溜めの段階で威力が上がる）

M4-1 で足した道具: `tools/motion-sheet.mjs`（モーションシート。`--aim` でロック中、`a-b:` で長押し）、`tools/motion-check.mjs`（床からの高さ・腕の到達・手首のねじれの数値検査。`--stats` / `--trace`）、`?sandbox=1`（敵なしで動きを撮る）。
新しい技の基準: 腕・脚のクランプ 0、上腕の挙上 130° 以下、手首のねじれ 150° 以下、剣先・頭・足が床の下に入らない。

### M4-2 盾・ガード・パリィ（片手剣 + 盾）（2026-10-04 実装。**実機で未確認**。ADR-020）
決定: **素手を標準にして盾は装備で出す**（2 系統 = 片手剣（素手 / 盾）と両手の大剣）。
- [x] ガードボタン（3 つ目のボタン。「重」の置き場所）: 押している間だけ構える（構えのあいだは動けず、向きだけ変えられる）。正面の攻撃を軽減して受け止める（盾 85% / 素手 50%）。**盾は構えに入ってから 10f がパリィ**（成功すると敵が大きく体勢を崩し、その間の攻撃が反撃として 2 倍のダメージ）
- [x] 盾（左前腕のメッシュ）、盾を持つときの左腕（攻撃・回避・待機を左腕固定で焼き直した版）、構え・受け・パリィの手付けクリップ（盾 / 素手の剣）、敵の「弾かれ」（体勢崩し）状態と見た目
- [x] 装備の組（ロードアウト）: 開始画面で選ぶ（保存）+ 戦闘中の切替ボタン。素手が標準
- [x] 効果音（ガード・パリィ・構え・装備切替）、ガード・パリィの演出（火花の色、水色の盾の光、PARRY の文字、画面の揺れ）、リザルトのパリィ回数

### M4-3 両手の大剣（2026-10-04 実装。**実機で未確認**。ADR-021）
本人の指示: **盾はないが大剣でも盾よりシビアなパリィが可能。被パリィ時の敵の挙動も盾とは異なる。大剣は重く手数は少ないが高火力広範囲で、色々なモーションが欲しい。**
- [x] 大剣のメッシュと、両手持ち（左手が柄を握る。手付けに `twoHanded`: 左手首を右手の握りと剣の向きから導く）。構え・待機・走り（腕は担ぎで固定、胴・脚は走りのまま）
- [x] 大剣の技 8 種（手付け）: 2 連（袈裟 → 逆袈裟）/ 踏み込み突き（牛の構え）/ 下がりながらの薙ぎ払い / 跳び上がる大回転斬り（全方位）/ ロール直後の跳び叩きつけ / 後ろステップ直後の斬り上げ / 長押しの溜め斬り（唐竹割り）。ダメージ約 2 倍・範囲広め・予備動作が長い・硬直が長い。大剣版のロール・後ろステップ
- [x] 大剣のガードとパリィ（盾なしでも可）: **受付 6f（盾 10f よりシビア）**、受け止めるだけの軽減は 65%。弾かれた敵は盾の体勢崩し（`stagger`）と違って**弾き飛ばされて倒れる**（`down`: 2.6m 飛び、1.9 秒動けず、反撃は ×2.4）。パリィの効果を構えごとのデータに分けた（`PARRY_EFFECTS`）
- [x] 大剣をロードアウトに足す（開始画面のチップ・切替ボタンは 3 つを順に回る。左手は柄を握るので盾は持てない）。効果音（大剣の振り 8 種・重いパリィ・倒れた音）、パリィの演出を効果ごとに（文字の大きさ・音・ヒットストップ・揺れ）
- 開発の道具: `?motionlab=1`（実リグで手付けを焼いて統計を返す。手首のねじれを減らす roll の探索に使った）、`tools/motion-check.mjs --weapon`、スクリーンショットに大剣のシーン
