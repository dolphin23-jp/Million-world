# 00. ビジョンとスコープ

## 何を作るか

iPad で遊ぶ、三人称視点のアニメ調 3D アクションゲーム。
プレイヤーは剣（将来はその他の武器・魔法）で敵と戦う。
個人用途。公開・販売・課金は一切想定しない。

## 絶対に守ること

**中途半端に放置しない。** まず「ゲームになっていなくても、移動・攻撃・敵を倒す」が成立する
デモを完成させ、そこから拡張する。デモ完成までは新システムを追加しない。

## 品質の軸

1. **アニメの絵が 3D で動いている感覚。** トゥーン着色・輪郭線・限定色・強い演出（剣筋、ヒットストップ、
   フラッシュ、カメラの揺れ）で成立させる。シェーダだけでなく演出の総体で「アニメらしさ」を作る
2. **手触り。** 入力に対する反応の速さ、攻撃の重さ、被弾の分かりやすさ。固定タイムステップと
   フレームデータ駆動で端末差なく再現する
3. **iPad で快適。** iPad Pro 2021（M1）で 60fps 安定。タッチ専用操作で片手ずつ親指操作が完結する

## デモ（M3）の完成定義

以下がすべて満たされた時点で「デモ完成」とし、拡張フェーズに入る。
**2026-10-04: 本人が iPad 実機で確認し、デモ完成とした。** 拡張フェーズ（`02-milestones.md` の M4〜）に入る。

- [x] iPad Safari / ホーム画面追加（PWA）で起動し、タップで開始できる
- [x] 左親指の仮想スティックで移動、右側のドラッグでカメラ回転、ボタンで攻撃・回避・ロックオン
- [x] プレイヤーキャラクターがアニメ調（トゥーン着色＋輪郭線）で、待機・走り・攻撃・回避・被弾・死亡のモーションを持つ
- [x] 弱攻撃 3 段コンボ。各段にフレームデータ（発生・持続・硬直・キャンセル受付）がある
- [x] 回避に無敵フレームがある
- [x] ロックオン: 最寄りの敵を対象にし、カメラとキャラの向きが対象を意識する
- [x] 敵 1 種以上: 追跡 → 予備動作（テレグラフ）→ 攻撃 → 硬直 の FSM。HP、被弾リアクション、死亡

- [x] HUD: プレイヤー HP、ロックオン対象の HP
- [x] 効果音（攻撃・命中・被弾・敵撃破）
