# 04. 操作系（タッチ専用）

横持ち iPad、両親指での操作を前提にする。すべて Pointer Events で実装し、タッチごとに
`pointerId` を追跡する（マルチタッチ）。

## 画面配置

```
+----------------------------------------------------------+
| [HP]                                        [敵HP(ロック時)] |
|                                                          |
|                                                          |
|     左半分: 浮動スティック           右半分: カメラドラッグ    |
|     （触れた位置が原点）                                     |
|                                                 [ロックオン] |
|                                            [回避]          |
|                         [スキル][薬瓶] [ガード]    [攻撃]   |
+----------------------------------------------------------+
（回避・ガードの左にアイテムボタン（薬瓶）、その左にスキルボタン（剣技）。右上に装備の切替ボタン。今の装備名が書いてある。その下に「メニュー」ボタン（未使用のポイントがあると金の点）。HP バーの左に Lv と経験値。画面の下の中央に操作ガイド）
```

- **左半分**: 触れた位置を原点とする浮動スティック。半径 ~70pt。原点から一定距離を越えたら原点が
  追従する（指が大きく動いても操作が切れない）
- **右半分（ボタン以外）**: ドラッグでカメラのヨー・ピッチ。慣性は付けない（酔い防止）。
  ロックオン中はピッチのみ有効
- **攻撃ボタン**（右下、最大）: 押した瞬間の状況で技が変わる（ADR-018）。コンボは連打、先行入力を受け付ける
  - タップ: 弱攻撃（袈裟 → 逆袈裟 → 突き）
  - **長押し**: 押した瞬間は 1 段目の予備動作に入り、0.15 秒押し続けると頭上の構えで止まる（溜め）。離すと重撃。構えが整ってから 0.4 秒・0.9 秒で段階が上がり（剣が光る・合図の音）、威力が 1.25 倍・1.6 倍。構えのあいだは動けず、回避でキャンセルできる
  - **スティックを倒して**押す: 前 = 踏み込み突き / 後ろ = 下がりながらの払い / 横 = 横薙ぎ（後ろ・横はロック中のみ。ロックなしは倒した向きへの踏み込み突き）。ロック中は「対象に対して」の方向
  - **回避の直後**に押す: ロールの後 = ダッシュ斬り（逆袈裟の斬り上げ）、後ろステップの後 = 踏み込み突き
  - **コンボの途中（次段の受付）でスティックを倒して**押す（ADR-023。ボタンは増やさない。そのまま押せば今までどおりの続き）:
    片手剣 = 1 段目 → 後ろ（ロック中）で**跳び退き斬り上げ** / 2 段目 → 横（ロック中）で**回転斬り**（全方位）/ 3 段目 → 前で**打ち上げ**（3 連の延長）。
    大剣 = 1 段目 → 横（ロック中）で**連携回転斬り**（全方位）/ 2 段目 → 前で**叩き落とし**（床を叩いて跳ね返る。2 連の延長）。ロックなしは「横」「後ろ」が無い（倒せば前）ので、前へ倒す延長（打ち上げ・叩き落とし）だけ出る
  - **大剣を持っているとき**は技が変わる（ADR-021。重く手数が少なく、高火力・広範囲）: タップ = 袈裟 → 逆袈裟の 2 連（2 連で終わる）/ 長押し = 0.2 秒で頭上の構え → 離すと唐竹割り（構えが整ってから 0.5 秒・1.1 秒で段階が上がり、威力 1.3 倍・1.8 倍）/
    スティック前 = 牛の構えからの踏み込み突き / 後ろ（ロック中）= 下がりながらの薙ぎ払い / 横（ロック中）= 跳び上がる大回転斬り（全方位）/ ロール直後 = 跳び叩きつけ / 後ろステップ直後 = 斬り上げ。**最大まで溜める**（押し始めて約 1.7 秒。剣の光の合図が 2 回）と、離したときに唐竹割りではなく**地割り**（さらに振りかぶって床へ叩きつける。衝撃の輪・砂ぼこり・ひび割れ・画面の揺れ。剣が床に弾かれて少し跳ね返る。硬直が長い）
  - **続きの技**（ADR-024。入力は同じ。連打 = そのまま押す、前 = 前へ倒して押す）: 片手剣 = 横薙ぎ → **返し薙ぎ** / 踏み込み突き → **抜き払い** / 跳び退き斬り上げ → 前で**飛び込み突き** / 打ち上げ → **落下斬り**（床を叩く）。
    大剣 = 踏み込み突き → **突き払い** / 下がりながらの薙ぎ払い → 前で**飛び込み突き** / 斬り上げ → **飛翔叩きつけ**（床を叩く）/ 溜め斬り → **地擦り斬り上げ**。どれも、前の技の振り抜きの姿勢を保っている間（受付）に押す
- **操作ガイド**（画面の下の中央。ADR-024）: 攻撃ボタンとスティックの向きで何が出るかを、いつも同じ 5 つの枠（● 連打 / ↑ 前 / ↔ 横 / ↓ 後ろ / ◉ 長押し）で見せる。
  - 立っているとき（薄く）: 枠 = 始動の技。**いまのスティックの向きで出る枠が金の縁**（倒しながら見れば、押す前に何が出るか分かる）。回避の直後は「ロール直後 → ダッシュ斬り」と一言
  - 攻撃中: 上に連携の履歴（袈裟斬り › 逆袈裟 › …。いまの技が金色）、枠 = 次に続けられる技、下に**受付の帯**（白 = 受付が開くまで / 金 = 受付中。縮んで 0 で連携が切れる）。先行入力を押してあれば ✓。続きの無い技は「この技で連携は終わり」
  - 溜め中: 段階（●）・次の段階までの帯・「離す → ○○」・「最大まで溜めると ○○」
  - 横・後ろの枠は**ロック中の向き**。ロックしていないときは点線・暗く 🔒（ロックなしでは倒した向きは全部「前」）
- **メニュー**（右上の「メニュー」ボタン、キーボードは M。閉じるのは「閉じる」・暗い背景・Escape / M）（ADR-033）: **一時停止メニュー**。開いているあいだは戦闘が止まる。タブで切り替える（機能が増えたらタブが増える）:
  - **ステータス**: Lv・経験値・ステータスポイント・スキルポイント。力 STR・器用 DEX・敏捷 AGI・知力 INT・体力 VIT（初期各 5）を **＋**（押し続けると連打）で振る。**−** は、メニューを開いてから振った分だけ戻せる。「ステータスを全部振り直す」は無料（二度押しで実行）。各行に効果が出る（ダメージ +3% など）
  - **スキル**: 武器の系統ごと（片手剣・大剣）のスキルを、スキルポイントで Lv1〜10 に上げる（＋ / −、全部振り直しは無料）。威力・クールダウン・連なりの数値と、Lv4・Lv7 の進化の説明が出る
  - **技表**: 装備の技を、始動の技 → 続く技の木で一覧する（旧「技表」ボタン）
  - **設定**: 「画面の下に操作ガイドを出す」のチェック（次回も保つ）、「最初から（セーブを消す）」（二度押しで実行）
  - レベルは敵を倒した経験値で上がる。**レベルが 1 つ上がるごとに、ステータスポイント +3・スキルポイント +1**。ボスが呼んだ手下は経験値 0。レベル・ポイント・振り分けは自動でセーブされる（このブラウザの localStorage）
- **回避ボタン**（攻撃の左上）: タップで回避。スティックを倒していればその向きへ**前転**（向きを変えて転がる）。入力なし、またはロック中に対象から離れる向きへ倒すと、向きを保ったまま**後ろステップ**
- **ガードボタン**（攻撃の左・回避の下。旧「重」の位置）: **押している間だけ構える**（ADR-020）。構えのあいだはその場から動けず、向きだけ変えられる（ロック中は対象へ）。
  - 構えの正面（盾 ±80° / 素手 ±60°）から来る攻撃を受け止める（盾 85% / 素手 50% 軽減。削りだけ通る）。横・背後からは防げない
  - **盾を持っているとき**: 構えに入ってから 0.17 秒のあいだに敵の攻撃が当たると**パリィ**（弾く。ダメージなし、敵が体勢を崩し、そのあいだ攻撃が反撃として 2 倍のダメージ）。受付のあいだ盾が水色に光る
  - **大剣を持っているとき**（盾なしでもパリィができる）: 受付は構えに入ってから **0.1 秒**（盾より厳しい）。弾くと敵は**弾き飛ばされて倒れ**（2.6m 離れて寝る）、倒れている約 1.4 秒のあいだ攻撃が**反撃として 2.4 倍のダメージ**。受け止めるだけのときは 65% 軽減（盾 85% / 素手 50%）で、失敗すると痛い
  - 構えに入って 4f 以降は、攻撃・回避でキャンセルできる（弾いたあとはそのまま反撃）。押したあとの先行入力は 12f
- **アイテムボタン**（回避・ガードの左。薬瓶の絵・選んでいるアイテムの名前・持っている数のバッジ）（ADR-030）:
  - **タップ**: 選んでいるアイテムを使う（薬瓶 = 体力が一瞬で回復。体力が満タン・持っていない・使い直しの待ち 0.75 秒のあいだは使えず、数は減らない）
  - **長押し（0.26 秒）または払う**: 一覧が**ボタンを中心にした同心円（扇）の上**に開く（真上を中心に、内側の輪から薬瓶（小）→ 薬瓶（中））。指をすべらせて**向き（と輪）**で選び、離すと、そのアイテムが「選んでいるもの」になる（使いはしない）。輪より遠くへ払っても、その向きの選択肢が選ばれる。ボタンの近く・扇と逆の向きで離すと取り消し（ADR-033）
  - 薬瓶は敵を倒すと確率で落ちる（拾う操作は要らない。頭上に「＋薬瓶（小）」が出て、自動でストックに入る）。ボスとボスが呼んだ手下は落とさない。何も落ちない撃破が続くと、いつか必ず 1 本落ちる
  - キーボードは U = 使う、I = 選択を次へ
- **スキルボタン**（アイテムボタンの左。剣の絵・選んでいるスキルの名前・`Lv` のバッジ）（ADR-031）:
  - **タップ**: 選んでいる**剣技**を使う。1 回の入力で、決まった順に技が**押さなくても自動で続く**（スティックで向きは変えられる）。立っている・走っている・攻撃や回避の次段の受付から始められる。剣技ごとに**専用の動き**で、被弾すると途切れる（竜巻・崩山の叩きつけ・一閃の溜めは**スーパーアーマー**: 軽い攻撃では怯まず「ARMOR」と出る。岩鬼・ボスの重い攻撃には割られる）。持続のあと（一閃は溜めの途中から）回避で連なりを捨てられる。使うとクールダウン（ボタンの上を暗い扇が回って消える）
  - **長押し（0.26 秒）または払う**: 一覧がボタンを中心にした**同心円（扇）の上**に開く（その装備の系統のスキル。名前・`Lv`。内側の輪に 5 個、次の輪に 8 個まで）。指をすべらせて向きで選び、離すと選び替わる（使いはしない）。ボタンの近く・扇と逆の向きで離すと取り消し
  - 装備を替えるとスキルの系統が替わる（片手剣・盾付きの片手剣 = 剣の剣技、大剣 = 大剣の剣技）
  - 剣技は全部 Lv1 で最初から使える。レベルはメニューのスキルタブでスキルポイントを使って上げる（Lv10 まで。Lv4・Lv7 で動きが進化する。ADR-034）。キーボードは O = 使う、P = 選択を次へ
- **ミスティカルドッジ**（ボタンはない。回避が成功すると起こる。ADR-030）: 回避（前転・後ろステップ）の**無敵のあいだに、当たるはずだった攻撃**（敵の近接・鬼火）があると発動する。**3 秒のあいだ無敵になり、敵と敵の弾だけが 1/5 の速さ**になる（自分は等倍。殴り放題の反撃の時間）。画面の縁が青紫に染まり、HP バーの下に残り時間のゲージが出る。**成功から 8 秒は次が起こらない**（ゲージが溜まっていくのが見える）。避けられる攻撃にはガード不能も含む（ガードは関係ない）。
- **装備の切替ボタン**（右上）: 押すと次の装備へ（片手剣 → 片手剣 + 盾 → 大剣 → …）。立っている・走っているあいだだけ。開始画面でも選べる（選んだものは次回も使う）。キーボードは G
- **ロックオンボタン**（右上寄り）: トグル。ロック中に右半分を横スワイプ（90px）で対象切替（右へ払えば右の敵）。対象が倒れたら残りへ自動で移る（ADR-016）。キーボードは L（ロック）、Q / E（切替）

## 設計上の約束

- ボタン領域の `pointerdown` はカメラドラッグに流さない（ボタン要素側で `stopPropagation`）
- 全タッチ領域に `touch-action: none`、`user-select: none`、`-webkit-touch-callout: none`
- ダブルタップ拡大・ピンチ拡大は `touchstart`/`gesturestart` の `preventDefault` で抑止
- スティック・カメラの感度は `src/input/data/touch.ts` に定数化する
- 入力は `InputIntent`（移動ベクトル、カメラ角速度、攻撃/回避/ガード/装備切替/ロック/アイテム使用/スキル使用の押下エッジ、アイテム・スキル選択の切替、攻撃・ガードを押している間の `attackHeld` / `guardHeld`）に抽象化し、
  ゲームロジックはタッチの存在を知らない。開発用にキーボード（WASD、J = 攻撃（押し続けると溜め）、K = 回避、H = ガード（押している間）、G = 装備の切替、L = ロック）も同じ `InputIntent` を出す

## カメラ

- 三人称、肩越しではなく背後やや上。距離 ~4.5m、注視点はキャラの胸の高さ
- 追従はクリティカルダンピング（ばねで遅れて付いてくる）。回転入力は即時反映
- ロックオン中: プレイヤーと対象の中点寄りを注視し、両者が映る距離に自動調整
- 壁との干渉回避はデモでは省略（アリーナは開けた空間）
