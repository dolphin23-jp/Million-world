# 04. 操作系（タッチ専用）

横持ち iPad、両親指での操作を前提にする。すべて Pointer Events で実装し、タッチごとに
`pointerId` を追跡する（マルチタッチ）。

## 画面配置

```
+----------------------------------------------------------+
| [HP]                                        [敵HP(ロック時)] |
|                                                          |
|                                                          |
|     左半分: 浮動スティック           右半分: カメラドラッグ    |
|     （触れた位置が原点）                                     |
|                                                 [ロックオン] |
|                                            [回避]          |
|                                       [ガード]    [攻撃]   |
+----------------------------------------------------------+
（右上に装備の切替ボタン。今の装備名が書いてある）
```

- **左半分**: 触れた位置を原点とする浮動スティック。半径 ~70pt。原点から一定距離を越えたら原点が
  追従する（指が大きく動いても操作が切れない）
- **右半分（ボタン以外）**: ドラッグでカメラのヨー・ピッチ。慣性は付けない（酔い防止）。
  ロックオン中はピッチのみ有効
- **攻撃ボタン**（右下、最大）: 押した瞬間の状況で技が変わる（ADR-018）。コンボは連打、先行入力を受け付ける
  - タップ: 弱攻撃（袈裟 → 逆袈裟 → 突き）
  - **長押し**: 押した瞬間は 1 段目の予備動作に入り、0.15 秒押し続けると頭上の構えで止まる（溜め）。離すと重撃。構えが整ってから 0.4 秒・0.9 秒で段階が上がり（剣が光る・合図の音）、威力が 1.25 倍・1.6 倍。構えのあいだは動けず、回避でキャンセルできる
  - **スティックを倒して**押す: 前 = 踏み込み突き / 後ろ = 下がりながらの払い / 横 = 横薙ぎ（後ろ・横はロック中のみ。ロックなしは倒した向きへの踏み込み突き）。ロック中は「対象に対して」の方向
  - **回避の直後**に押す: ロールの後 = ダッシュ斬り（逆袈裟の斬り上げ）、後ろステップの後 = 踏み込み突き
  - **大剣を持っているとき**は技が変わる（ADR-021。重く手数が少なく、高火力・広範囲）: タップ = 袈裟 → 逆袈裟の 2 連（2 連で終わる）/ 長押し = 0.2 秒で頭上の構え → 離すと唐竹割り（構えが整ってから 0.5 秒・1.1 秒で段階が上がり、威力 1.3 倍・1.8 倍）/
    スティック前 = 牛の構えからの踏み込み突き / 後ろ（ロック中）= 下がりながらの薙ぎ払い / 横（ロック中）= 跳び上がる大回転斬り（全方位）/ ロール直後 = 跳び叩きつけ / 後ろステップ直後 = 斬り上げ
- **回避ボタン**（攻撃の左上）: タップで回避。スティックを倒していればその向きへ**前転**（向きを変えて転がる）。入力なし、またはロック中に対象から離れる向きへ倒すと、向きを保ったまま**後ろステップ**
- **ガードボタン**（攻撃の左・回避の下。旧「重」の位置）: **押している間だけ構える**（ADR-020）。構えのあいだはその場から動けず、向きだけ変えられる（ロック中は対象へ）。
  - 構えの正面（盾 ±80° / 素手 ±60°）から来る攻撃を受け止める（盾 85% / 素手 50% 軽減。削りだけ通る）。横・背後からは防げない
  - **盾を持っているとき**: 構えに入ってから 0.17 秒のあいだに敵の攻撃が当たると**パリィ**（弾く。ダメージなし、敵が体勢を崩し、そのあいだ攻撃が反撃として 2 倍のダメージ）。受付のあいだ盾が水色に光る
  - **大剣を持っているとき**（盾なしでもパリィができる）: 受付は構えに入ってから **0.1 秒**（盾より厳しい）。弾くと敵は**弾き飛ばされて倒れ**（2.6m 離れて寝る）、倒れている約 1.4 秒のあいだ攻撃が**反撃として 2.4 倍のダメージ**。受け止めるだけのときは 65% 軽減（盾 85% / 素手 50%）で、失敗すると痛い
  - 構えに入って 4f 以降は、攻撃・回避でキャンセルできる（弾いたあとはそのまま反撃）。押したあとの先行入力は 12f
- **装備の切替ボタン**（右上）: 押すと次の装備へ（片手剣 → 片手剣 + 盾 → 大剣 → …）。立っている・走っているあいだだけ。開始画面でも選べる（選んだものは次回も使う）。キーボードは G
- **ロックオンボタン**（右上寄り）: トグル。ロック中に右半分を横スワイプ（90px）で対象切替（右へ払えば右の敵）。対象が倒れたら残りへ自動で移る（ADR-016）。キーボードは L（ロック）、Q / E（切替）

## 設計上の約束

- ボタン領域の `pointerdown` はカメラドラッグに流さない（ボタン要素側で `stopPropagation`）
- 全タッチ領域に `touch-action: none`、`user-select: none`、`-webkit-touch-callout: none`
- ダブルタップ拡大・ピンチ拡大は `touchstart`/`gesturestart` の `preventDefault` で抑止
- スティック・カメラの感度は `src/input/data/touch.ts` に定数化する
- 入力は `InputIntent`（移動ベクトル、カメラ角速度、攻撃/回避/ガード/装備切替/ロックの押下エッジ、攻撃・ガードを押している間の `attackHeld` / `guardHeld`）に抽象化し、
  ゲームロジックはタッチの存在を知らない。開発用にキーボード（WASD、J = 攻撃（押し続けると溜め）、K = 回避、H = ガード（押している間）、G = 装備の切替、L = ロック）も同じ `InputIntent` を出す

## カメラ

- 三人称、肩越しではなく背後やや上。距離 ~4.5m、注視点はキャラの胸の高さ
- 追従はクリティカルダンピング（ばねで遅れて付いてくる）。回転入力は即時反映
- ロックオン中: プレイヤーと対象の中点寄りを注視し、両者が映る距離に自動調整
- 壁との干渉回避はデモでは省略（アリーナは開けた空間）
