# 03. 資産パイプライン

## 役割分担

- **本人**: 重要キャラクターの原案画像を生成（ChatGPT 画像生成）→ Tripo で 3D 化 → GLB をチャットに添付
- **AI（このリポジトリの作業者）**: 検査・正規化・削減・トゥーン化・リグ/モーションの統合、
  重要でない敵・小物の生成と量産

## 予算（iPad Pro 2021 / 60fps 目標）

| 対象 | 三角形数 | テクスチャ | 備考 |
|---|---|---|---|
| プレイヤー | ≤ 40k | 最大 2048² ×1 または 1024² ×2 | 常時画面中央にいるので最も高く |
| 雑魚敵 | ≤ 20k | 1024² ×1 | 同時 5〜8 体 |
| ボス | ≤ 60k | 2048² ×1 | |
| 小物・環境 | 合計 ≤ 100k | 1024² 以下 | |
| 画面全体 | ≤ 300k | | シャドウパス込みで余裕を見る |

## プレイヤー原案画像の生成仕様（ChatGPT へ渡す条件）

- 全身。**A ポーズ**（腕を体側から約 30° 開く、脚は肩幅、指は軽く開く）。T ポーズも可
- **正面・真横・背面の 3 面図を 1 枚に**（キャラクターシート）。同一キャラクターと明記
- **フラット塗り、陰影は最小限**。ドラマチックな照明なし。白または単色背景
- **武器は持たせない**（剣は別途生成し、手ボーンに装着する）
- 髪は顔を隠さない。体から離れた細い装飾（マフラー・リボン・鎖）、裾の広がった服・マントは避ける
  （生成 3D は細いものを塊にし、揺れ物は剛体になる）
- 髪型は短髪〜ひとつ結び程度を推奨（揺れなくても不自然でないもの）
- 無表情〜薄い微笑み。口は閉じる
- 画風: アニメ調。線画ではなく、面で塗られた立体感のあるセルルック

## Tripo での 3D 化手順

1. 3 面図を正面 / 側面 / 背面に切り出し、**マルチビュー入力**で生成（単一画像より形状が安定する）
2. スタイル指定にカートゥーン/アニメ系の選択肢があれば選ぶ。なければ既定
3. 生成後、ポリゴン数指定やリメッシュ機能があれば **40k 前後**を指定（無ければ後段で削減する）
4. **自動リグ**があれば適用し、「リグ付き GLB/FBX」と「リグなし GLB」の両方を書き出す
5. テクスチャは PBR 一式で可（使うのはベースカラーのみ）

## 検査基準（プレイヤー採用ゲート）

AI が GLB を読み込み、以下を確認して合否と理由を返す。

| 項目 | 合格条件 |
|---|---|
| 顔（正面） | 目・口の位置と形が原案と一致し、潰れていない |
| 顔（側面 / 斜め 45°） | 鼻・顎・目のくぼみが破綻していない。目が「顔に貼った絵」になっていない |
| 手 | 5 指が分離しているか、少なくとも拳として成立している（剣を握れる） |
| トポロジー | 肘・膝・肩の周辺に十分な分割があり、曲げたときに潰れない |
| 法線 | 平滑化後に輪郭線（inverted hull）が破綻しない |
| テクスチャ | ベースカラーに強い陰影の焼き込みがない（トゥーン着色と喧嘩しない） |
| リグ | 標準的なヒューマノイド骨格（hips/spine/chest/neck/head/肩/上腕/前腕/手/大腿/下腿/足）がある、または Mixamo 自動リグで通る |

**判定**: 顔（側面）と手が不合格なら VRoid 経路へ切替（ADR-005）。他は後段で修正可能。

## リグとモーション

- Tripo のリグが標準ヒューマノイドなら、Mixamo のモーションをボーン名マッピングでリターゲットする
- Tripo のリグが使えない場合: 本人が Mixamo（Web）に FBX をアップロードし自動リグ（マーカー配置 5 分）。
  「with skin」で 1 本、以降は「without skin」でモーションのみダウンロード
- 必要モーション（M1）: Idle, Run, Sword Slash ×3（コンボ用）, Dodge Roll, Hit Reaction, Death
- 変換: FBX → glTF（Blender ヘッドレス or FBX2glTF）。モーションは 1 ファイルに複数クリップでまとめる

## 正規化・削減スクリプト（`tools/import-character.ts`）

入力 GLB に対して以下を自動で行い、`public/assets/characters/<name>.glb` を出力する。

1. 向きを +Z 正面、+Y 上に揃え、足裏を原点、身長を指定値（既定 1.65m）にスケール
2. 法線の平滑化（角度閾値付き）と頂点結合
3. メッシュ簡略化で三角形数を予算以下に（gltf-transform / meshoptimizer）
4. テクスチャを予算サイズ以下にリサイズ、ベースカラー以外を破棄
5. マテリアルを `ToonMaterial` 用のメタデータ（影色・リム強度の初期値）に置換
6. meshopt 圧縮で出力。検査レポート（三角形数・テクスチャ・ボーン一覧）を `artifacts/` に出す

## 剣・小物

- Tripo で単体生成（白背景、横向き全体図）。≤ 5k 三角形
- 剣は柄の根元を原点、刃先を +Y に正規化し、手ボーンのオフセットはデータで調整する

## 命名・配置

```
public/assets/characters/<name>.glb          正規化済みキャラ
public/assets/animations/<set>.glb           モーションクリップ集
public/assets/props/<name>.glb               武器・小物
public/assets/env/<name>.glb                 環境オブジェクト
raw/                                         生成直後の元データ（git 管理外、Git LFS も使わない）
```
