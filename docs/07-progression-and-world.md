# 07. 成長・スキル・武器・ステージの設計（M6 以降）

**状態: 方針を決定（2026-10-04、本人の指示。ADR-031）。** 実装は M6-1（スキル欄とアクティブスキル）から。数値は仮置きで、各段階で実機を触って詰める。
この文書は「何を・どの順で作るか」と「いま入れておくと後で効く土台」を決める。決まったことは ADR-031、進み具合は `docs/02-milestones.md`。

## 0. 本人の指示（要約）

1. **スキル欄**を作る。スキルは **アクティブ**（一連の剣技）と **パッシブ**があり、どちらも**スキルレベル**方式。
2. **成長**は STR / DEX / INT / AGI などの**ステータス振り**（よくある形式）。
3. **武器の種類・強化**はおいおい拡充する。
4. **ステージ**は、いまは闘技場のように進むデモ。最終的には**ダンジョン / オープンフィールド**で戦い、**地形・障害物も戦闘に生かす**。ただし**実装の順は考慮**する。

## 1. 全体の順序（結論）

| **M7-1** | **世界の土台**: 障害物の衝突・遮蔽（弾・視線）を `World` として束ねる。闘技場は `World` の 1 実装になる。**実装済み（ADR-039）** | 地形を戦闘に生かす構想の全部が乗る土台。足の高さ `y` と障害物の上面 `top` を最初から問い合わせの引数に持つ（縦の動きが入っても API が変わらない） |

| **M7-3** | **乗り越え・掴んで登る**: 低い障害物は自動で越える（ボタンを足さない。**M7-3a 実装済み（ADR-041）**）、高い縁は掴んで登る（登れる縁はステージのデータで明示。クリップは高さの生成関数。**M7-3b 実装済み（ADR-042）**） | 縦の動きの上に乗る。掴み・引き上げの手付けと、ルートの高さ（rootY）・手の IK・カメラの追従が要るので最後 |
| **M7-4** | **地形を戦闘に使う**（ADR-043 で 3 段に分けた）: **M7-4a 敵の迂回（ステアリング）・カメラの衝突（実装済み）**、M7-4b 高さと視線（近接の縦の届き・登った縁の上の安全地帯・ロック / 遠距離の視線・突進の壁への激突）、M7-4c 壊せる物・床の危険地帯 | 既存の敵の個性（突進・遠距離・群れ）が、地形で別の遊びになる |
| **M8** | 武器の拡充と強化（槍・双剣…、+n の強化、素材） | 武器 1 種ごとにモーションが数時間かかるので、土台（成長・スキル・世界）の後に |
| **M9** | **ダンジョン**: ステージの定義データ・部屋と通路・出現のトリガー・ミニマップ・敵の巡回 | `Encounter`（ウェーブ）を「部屋のトリガー」に置き換える |
| **M10** | **オープンフィールド**: チャンク読み込み・LOD・視界で気づく敵 | 最後。描画と資産の負荷が主題 |

- **成長・スキル（M6）を地形（M7）より先にする理由**: 成長もスキルもステージに依存しないので、闘技場のまま作って確かめられる。逆に地形は、戦闘の中身（敵・弾・技）が固まっているほど作りやすい。
- **武器（M8）を後ろに置く理由**: 武器は「モーション制作」が重く（1 種に数時間）、ステータスの効き方（§3.2 の武器補正）とスキルの武器別の枠が決まってから作ったほうが手戻りがない。**武器の種類を足すたびにスキルの枠が増える**ので、スキルの仕組みが先。
- 順序はこの文書を更新して入れ替えられる。M6-1 だけは確定。

## 2. スキル

### 2.1 アクティブスキル（剣技）
- **剣技 = 専用モーションの連なり**（ADR-032。M6-1 当初の「既存の技をつなぐだけ」から、本人の指示で変更）。1 回の入力で、決まった順に技が自動で続く（スティックで向きは変えられる）。多くは**3 連以上か、1 つの技に複数ヒット**を持ち（一閃のような 1 撃の大技もある）、**途中で回避でやめられる**。**無敵は付けない**。**敵の攻撃で途切れる剣技**と、**一部にスーパーアーマー**（軽い攻撃では怯まない。岩鬼・ボスの重い攻撃には割られる）がある。途中に既存の技を混ぜてもよい。連なりのつなぎは、次段のクリップが前段の受付時刻の姿勢から始まること（`continueFrom` = `cancelAt`。テストで保証する）。
- **レベル 1〜10**: 数値は**なめらか**に伸びる（威力 +5%/Lv・クールダウン −3.5%/Lv。Lv10 で +45% / −31.5%）。**モーションが変わるのは Lv4 と Lv7 の 2 段階だけ**（連なりに段が足される・段が別の動きに差し替わる。2.1.3・ADR-034 = **実装済み**）。
- **コスト = クールダウン**（スキルごと）。「ゲージ・MP を貯める」案は今は採らない（理由: 画面の部品が増える・攻撃・回避・ガード・アイテムと並んで管理が増える・クールダウンはボタンの見た目だけで分かる）。INT でクールダウンが縮む（§3.2）。
- **武器の系統ごと**に覚える・使える（片手剣 / 盾付きの片手剣は同じ「剣」の系統、大剣は別）。装備を替えるとスキル欄の中身も替わる。
- **使い方**: スキルボタン（アイテムボタンの左）。**タップで選んでいるスキルを使う**、**長押しか上への払いで一覧**が開いて選び替える（`SlotButton`。アイテム欄と同じ部品）。クールダウン中はボタンに暗い扇が回る。キーボードは O = 使う、P = 選択を次へ。
- 使えるとき: 立っている・走っている・攻撃の次段キャンセルの受付・回避のキャンセルの受付。被弾・死亡で連なりは途切れる（アーマーの区間は除く）。回避でのキャンセルは剣技ごとの時刻から効く（連なりを捨てて回避。溜めのある一閃は溜めの途中から）。

#### 2.1.1 実装済みの剣技（M6-1。数値は ADR-032 の表）
- **片手剣**: **四ツ葉**（右袈裟 → 右逆袈裟 → 左袈裟 → 左逆袈裟の 4 連）・**五月雨突き**（フェンシングの構えから高速の突き 5 連。細く前へ長い）・**竜巻**（2 周半の回転斬り。前の半円 3 回・後ろ 2 回。回っているあいだアーマー）。
- **大剣**: **崩山**（右払い → 左払い → 頭上から叩きつけ。衝撃波が地面と周囲へ。叩きつけにアーマー）・**一閃**（後ろへ引いて溜め（アーマー）→ 一瞬のダッシュ → 水平に大きく斬る 1 回）。

#### 2.1.1b 実装済みの剣技 第 2 弾（M6-6。ADR-038。数値は ADR の表）
- **片手剣**: **居合**（納刀の構えで溜め → 一瞬のダッシュ → 左から抜き打ち → 返しの斬り上げ。Lv4 袈裟・Lv7 突きが続く）・**十字斬り**（縦 → 横 → 交点に突き立てて円の衝撃。十字が 1 → 2 → 3 回）・**疾風連斬**（駆けながら横薙ぎを左右に切り返す 4 → 6 → 8 太刀）。

#### 2.1.3 レベルでモーションが進化する（**決定・実装済み（M6-3b）: 数値はなめらかに、モーションは Lv4 と Lv7 の 2 段階。最大 Lv10。ADR-033・034**。以下は検討の記録。実際の中身は ADR-034 の表）
本人の案: 「レベルアップで威力だけでなく**モーションが進化していく**のも面白そう」。進化させる手段は 3 段階あり、手間が違う。
1. **段を足す**（今の仕組みで入る）: `SkillStepDef.minLevel`。例: 四ツ葉は Lv3 で 5 段目（回し斬り）、Lv5 で 6 段目（突き込み）。クリップ 1 本ずつ。
2. **段を別の動きに差し替える**（`evolve`）: 例: 崩山の叩きつけが Lv5 で「叩きつけ → 衝撃波が 2 重（遅れて外側へ 2 つ目）」に、一閃が Lv3 で「斬り抜けたあと返しの斬り」付きに。`SkillStepDef.evolve: [{ minLevel, attack }]`（その段を `attack` に差し替える）を足せばよい。差し替えのクリップは元のクリップを素材に作れる（前半は共有）。
3. **同じクリップで当たり・数を変える**（クリップ不要）: Lv ごとに窓の数・範囲・アーマーの強さを変える。例: 竜巻の回転を 2.5 周 → 3.5 周（窓を足す。ただし回転のクリップは周回ぶんの長さが要る）、五月雨の突きを 5 → 7 回（突きの時刻がクリップに焼かれているのでクリップも要る）、崩山の衝撃波の半径 +10%/Lv、一閃のダッシュ距離 +0.3m/Lv・溜めの時間 −0.05 秒/Lv。**クリップに依存しない数値（半径・距離・溜め・アーマーの強さ）はレベルで滑らかに伸ばし、モーションの変化は Lv3 と Lv5 の 2 段階だけ**にする案を推す（制作の量が読める）。
- スキルレベルは M6-2 で入った（スキルポイントで Lv1〜10）。`SkillBook` の `skillSteps(def, level)` が窓口なので、(1)(2) はここで解決でき、戦闘のコードは触らない。**M6-3b（ADR-034）で実装**: 5 つの剣技すべてに Lv4・Lv7 の進化（四ツ葉 + 突き込み / + 回し斬り、五月雨 5 → 7 → 9 連、竜巻 2.5 → 3.5 → 4.5 周、崩山 飛翔崩山 / + 地裂、一閃 + 返し斬り / + 突き抜け）。採らなかった案: 窓の数・範囲を Lv ごとに連続で変える（3。クリップに焼かれた時刻と食い違う）。

- **将来の拡張**（枠だけ空けておく）: 無敵フレーム（付けない方針だが、特別な剣技だけ）・飛ぶ斬撃（弾）・状態異常。魔法系のアクティブ（INT 依存。詠唱・投射物）。

### 2.2 パッシブスキル（M6-5 で実装。ADR-037）
- **常時効く**。レベル 1〜5（強いものは 1〜3）。効果は**`Modifiers` のキー**への加算 / 乗算（§3.3）と、**イベントで発動する小さな効果**（パリィ成功時に回復など）の 2 種類。
- **実装した 12 種**（`src/combat/data/passives.ts`。下の案から、剣術習熟・剛力習熟・会心の心得（新）・急所突き（新）・連撃の心得・闘気・見切り・受け流し・追い打ち・身軽・鉄壁・薬師）。案との違い: 見切りのミスティカルは +0.2 秒、受け流しはパリィの受付だけ（ガードの受付は広げない）、闘気は 1 回 +2% × 最大 5 重なり、連撃の心得は剣技の連なりの 3 段目以降にも効く、剛力習熟は溜めの速さでなくふっ飛ばし +3%（溜めの速さは DEX と役割が被るため）。会心の心得・急所突きは M6-3a（会心）に合わせて足した。
- 案（初期の候補。実機で触って増減する）:

| 名前（仮） | 効果（1 レベルあたり） | 系統 |
|---|---|---|
| 剣術習熟 | 剣の系統の攻撃ダメージ +4% | 剣 |
| 剛力習熟 | 大剣のダメージ +4%・溜めの速さ +3% | 大剣 |
| 見切り | ミスティカルの続く時間 +0.3 秒・回避の無敵 +1f | 共通 |
| 受け流し | パリィ・ガードの受付 +1f・パリィ成功で体力 +2 | 共通（盾・大剣） |
| 身軽 | 移動 +2% | 共通 |
| 鉄壁 | 受けるダメージ −3% | 共通 |
| 薬師 | 薬瓶の回復量 +10%・ドロップ率 +5% | 共通 |
| 連撃の心得 | 連携の 3 段目以降のダメージ +4% | 剣 |
| 闘気 | 敵を倒すと 4 秒間、攻撃力 +3%（重なる・上限あり） | 共通 |
| 追い打ち | 弾かれた敵・体勢が崩れた敵への攻撃 +6% | 共通 |

### 2.3 スキルポイントとツリー
- **スキルポイント（SP）**: レベルアップごとに **1**（本人の指示）。**スキルを 1 レベル上げるのに 1 ポイント**（Lv1 → Lv10 は 9 ポイント。Lv30 の SP 29 で 3 本ぶん = **全部は取れない**・選ぶ楽しみ）。**全アクティブスキルを Lv1 で習得済みから始める**（M6-1 の感触を保つ。習得制はパッシブにだけ入れた = M6-5）。
- **前提・ツリー・パッシブ**（M6-5 で実装。ADR-037）: **パッシブは Lv0（未習得）から始め、1 ポイントで習得・1 ポイントで 1 レベル**（アクティブの剣技と同じポイント。全部取ると 52 ポイントで Lv30 でも足りない）。前提のあるパッシブは、前提のパッシブが指定のレベルになるまで習得できず、前提を割る取り下げもできない（会心の心得 Lv2 → 急所突き、連撃の心得 Lv2 → 闘気、見切り Lv1 → 受け流し Lv1 → 追い打ち）。**アクティブの剣技の前提**（例: 五月雨 = 剣術習熟 Lv2）は、剣技を全部 Lv1 から使える今の感触を保つため、まだ入れていない（剣技が増える次の段階で、本人の様子を見て）。
- **リセット**: スキル・ステータスの振り直しは、いつでも無料（メニューから。二度押しで実行）。試行錯誤を罰しない。メニューを開いてから振った分は − でも戻せる。

## 3. 成長（ステータス）

### 3.1 経験値とレベル
- 敵を倒すと経験値（`EnemyDef.xp`）、クリアのランクでボーナス。**セーブされる**（§3.4）。闘技場は繰り返し遊べる訓練場として、周回で育つ。
- 目安: デモ 1 周（約 660 xp）で Lv 7 前後、5 周で Lv 15 前後。1 レベルごとに **ステータス 3 ポイント + スキル 1 ポイント**。上限は Lv 30（内容が増えたら伸ばす）。
- **難易度は育てても崩れない**: 初期（Lv1・ステ振りなし）のままで、今のボスまでの歯応えを保つ（本人が「これで良い」と決めた）。成長は「楽をする」ためではなく「別の遊び方・周回の強い難易度」のためにある。**強い難易度 = 敵の色違い・段階（M6-4。ADR-036）**: 成長に合わせて、敵が紅・蒼・黒の強化版になっていく。

### 3.2 ステータスと効き方
| ステータス | 効くもの（案） |
|---|---|
| **STR（力）** | 攻撃ダメージ（武器の補正が大きい武器ほど効く）・ノックバック・体勢削り・重い武器の装備条件 |
| **DEX（器用）** | 攻撃の速さ（モーション倍率）・**クリティカル（会心）率と倍率（実装済み。ADR-035）**・パリィ / ガードの受付フレーム・溜めの速さ |
| **AGI（敏捷）** | 移動速度・回避の無敵フレームと硬直・ミスティカルの続く時間 |
| **INT（知力）** | スキルのクールダウン短縮・スキルの威力・薬瓶の回復量・将来の魔法 |
| **VIT（体力）** | 最大体力・受けるダメージ軽減・（将来）プレイヤーの体勢 |

- 初期値は各 5。1 ポイントの効きは小さく（1% 前後）、**振った点が 30 を超えた分は効き半分**（逓減）。数値は `src/combat/data/stats.ts` に集めた（**実装済み。実際の数値は ADR-033 の表**。DEX の攻撃速度は `AttackDef.rate` に掛ける）。
- **武器補正**（Souls の A/B/C 風）: 武器ごとに STR / DEX / INT の補正（ランク）を持ち、ダメージ = 基礎 × (1 + Σ ランク係数 × ステータス)。大剣は STR、軽い剣は DEX、のように性格が出る。M8 で武器データに入れる。

### 3.3 効果の集計（`Modifiers`）— いちばん大事な土台
- ステータス・パッシブ・（将来）武器・装備の効果は、**1 か所の純粋関数 `computeModifiers(stats, skills, equipment) → Modifiers`** に集める。戦闘のコードは **`Modifiers` だけを読む**（ダメージ倍率・クールダウン倍率・移動速度・攻撃の速さ・最大体力・被ダメージ倍率・回復倍率・ミスティカル持続・受付フレームの加算 …）。
- こうしておくと、**武器の強化・装備・状態異常・ダンジョンの祝福**など、後から入る要素も「`Modifiers` に足す」だけで済み、戦闘のコードを触らない。数値の整合はテストで保証する。
- **イベントで発動する効果**（パリィ成功・撃破・ジャスト回避 …）は、戦闘が出す合図（すでにある `onParry` / `onJustDodge` / 撃破）に、小さな効果の表を結び付けて起こす（M6-3）。

### 3.4 セーブ
- **`localStorage`**（Safari のプライベートモードで例外・容量切れがあるので、読み書きは try/catch で包み、使えないときは「セーブなし」で動く）。キー `mw.save`、`{ version, level, xp, stats, statPoints, skillPoints, skills, equipped, selected, loadout }`。**バージョン番号 + 移行関数**（データ構造を変えても古いセーブを壊さない）。
- 保存するタイミング: レベルアップ・ステ振り・スキル振り・装備の変更・戦闘の終了。**戦闘の途中の状態（敵・体力・アイテム）は保存しない**（闘技場は 1 回ごとの挑戦）。アイテムの持ち越しはダンジョンができてから。
- キャラ画面に「最初から」（セーブの消去・確認つき）。

### 3.5 画面
- **一時停止メニュー**（実装済み。ADR-033。右上の「メニュー」ボタン。開いている間は戦闘を止める）: タブ **ステータス / スキル / 技表 / 設定**。機能が増えるごとにタブを足す（装備（M8）・持ち物・図鑑など）。ステータスはポイントを振る +/−（開いてから振った分だけ戻せる・全部振り直しは無料）、スキルは武器の系統ごとにレベルを上げる（M6-3 でツリー・前提・スキル欄に出すスキルの選択を足す）。

## 4. 武器の拡充と強化（M8。方針だけ）
- 武器は `WeaponDef`（種類・基礎の攻撃力・補正ランク・装備条件・技のセット）+ **強化レベル +0〜+10**（基礎 × (1 + 0.06 × n)。素材は敵のドロップ = アイテム欄の仕組みで持つ）。いまの `LOADOUTS`（装備の組）は、その中の「武器 + 左手」の組として残る。
- 種類を足す順の案: 槍（突きの間合い）→ 双剣（手数・速さ）→ 短剣・斧・杖（魔法の媒体。INT）。**1 種ごとに、モーション（手付け）・技のセット・ガード・見た目（メッシュ）・スキル 8〜10 本**が要る。
- スキルは**武器の系統に紐づく**ので、武器を足すたびにスキルの枠と表が増える。仕組み（§2）が先で、中身はデータの追加で済むようにしておく。

## 5. ステージの構想（ダンジョン / オープンフィールド）と、いま入れておく土台

### 5.1 いまの世界
**M7-1（ADR-039）で `World` を入れた**。闘技場は円の境界 + 円柱・箱の障害物（柱・折れた柱・低い岩・壁・箱。`src/world/data/arena-props.ts`）で、体の押し出し・弾の遮蔽・出現の範囲は `World` を通る。**M7-2（ADR-040）で縦（足の高さ・ジャンプ・足場）が動く**: 低い岩・壁（0.85〜0.9）には乗れ、石の箱（1.5）には跳んでも乗れない（M7-3b で掴んで登る）。**M7-3a（ADR-041）で低い障害物（〜1.2m）は自動で越える**（乗り上がり・乗り越え）。**M7-3b（ADR-042）で登れる縁（箱 1.5・壇 2.2。金色の縁取り）を掴んで登れる**。**M7-4a（ADR-043）で敵が障害物を回り込んで追い、カメラが柱の手前で止まる**。敵はまだ y を持たない。以下は M7-1 の前の記述:

闘技場は 1 枚の円（`Arena`）。当たりは XZ の円どうしの押し出しと、円の縁へのクランプだけ（`clampInsideArena` / `pushOutOfCircle` / `separateCircles`）。**障害物・高低差・視線の遮りはない**。敵の AI（`Enemy.step`）・飛び道具（`ProjectileSystem.step(dt, arenaRadius)`）・予告の床表示・カメラは、どれも「円の闘技場」を前提にしている。

### 5.2 地形を戦闘に生かすための要素（段階順）
1. **静的な障害物**（柱・岩・壁。円と箱）: 体の押し出し、**弾の遮蔽**（柱の陰で鬼火を防ぐ）、**視線の遮り**（ロックオン・敵の視界）、突進が**壁に当たって止まる**（激突の隙 = 新しい反撃の窓）、床の予告が障害物で途切れる。
2. **敵の経路**: 障害物を避けて追う（まず「ステアリング」= 近いものを避ける、次に**格子の経路探索 / フローフィールド**）。部屋・通路で必須。
3. **壊せる物・動かせる物・仕掛け**（樽・燭台・落石・床の罠）、**危険な床**（穴・毒沼・溶岩）。敵も巻き込める。
4. **高低差**（段差・坂・崖）。ここだけは**物理の見直し条件**（ADR-002: 段差のある地形が欲しくなったら Rapier を検討）に触れる。まず 1〜3 を自前で作り、高低差が本当に要るときに判断する。
5. **カメラ**: 壁・天井にめり込まない（遮蔽物との衝突・半透明）。屋内では引きを抑える。
6. **ステージの定義データ**（`StageDef`: 部屋・通路・障害物・出現表・トリガー・扉・宝箱）と読み込み。`Encounter`（ウェーブ）は「部屋に入ったら出る敵のトリガー」の 1 種になる。
7. **オープンフィールド**: チャンクの読み込み・遠景の LOD・敵の視界 / 聴覚での気づき・巡回・拠点（セーブ地点）。

### 5.3 いま（M6 のうち）に守ること — 後で書き直しにしないための約束
- **成長・スキル・アイテムの状態は、闘技場に依存させない**（`Encounter` や `arena` を参照しない）。経験値は「撃破の合図」から受け取る（`Encounter` を経由しない）。ステージが変わっても同じ状態を持ち越せる。
- **戦闘のコードは数値を `Modifiers` から読む**（§3.3）。ステージ・装備・状態異常が足されても戦闘のコードは変わらない。
- **世界への問い合わせは 1 か所に集める**: M7-1 で `World`（`moveCircle` = 押し出し、`raycast` = 線分が遮られるか、`contains` …）を作り、`Enemy.step` / `ProjectileSystem.step` / 予告の床表示 / ロックオン / カメラが、円の半径ではなく `World` を呼ぶようにする。M6 の間に新しく書く「世界に触る」コードは、`arena.radius` を直接読まず、**既存の `clampInsideArena` のような 1 点の入口**を通す（直接書き散らさない）。
- **出現と進行は「トリガー」で考える**: 新しい出現の仕組みは `Encounter` のウェーブに埋め込まず、「条件 → 出現」の形にしておく（M9 で部屋のトリガーに差し替えられる）。

## 6. 決めていないこと（先に聞く・実機で決める）
- スキルのコストをクールダウンのみにするか、ゲージ（MP / 気力）を足すか（まず前者。実機で物足りなければ足す）。
- 経験値の曲線・ステータスの効きの細かい数値（M6-2 で仮置き → 実機で調整）。
- ~~周回の強い難易度（敵の倍率）を入れるか~~ → **入れる。敵の色違い・段階（壱 並 / 弐 紅 / 参 蒼 / 肆 黒）として実装済み（M6-4。ADR-036）**。倍率だけでなく色・大きさ・一部の技（提灯の扇・ボスの号令）が変わる。育成の天井はレベル 30（肆の 1 周で届く）。
- アイテムのセーブ（持ち越し）はダンジョンから。
- 魔法（INT 系のアクティブ）の形式（詠唱・投射物・範囲）は M6-4 以降。
